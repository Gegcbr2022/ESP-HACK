# Можно ли подключить Wemos / LOLIN D1 mini

Да, D1 mini на ESP8266 можно связать с основным ESP32 отдельным UART.
Практичный вариант — три сигнальных провода и отдельное USB-питание каждой
платы. Это предложение для следующего этапа разработки: текущая прошивка
ESP-HACK не содержит такого моста, а одно подключение проводов функций
не добавляет. Для работы нынешнего ESP32 с OLED, SD и CC1101 D1 mini не нужен.

Этот документ проверяет осуществимость подключения. Прошивка ESP8266,
изменение текущей распиновки ESP32 и испытание двух плат здесь не выполнены.

## Варианты

| Вариант | Что потребуется | Когда удобен |
|---|---|---|
| Каждая плата отдельно по USB | Два USB-подключения; для обмена через компьютер понадобится программа-мост | Сначала проверить обе платы по отдельности, не меняя рабочую сборку |
| UART между платами | Три провода, общий GND, отдельная программа для D1 mini и поддержка моста на ESP32 | Обмен короткими командами и состоянием без компьютера-посредника |
| Обмен по Wi-Fi | Прошивки обеих плат с согласованным протоколом | Если принципиально нужно обойтись без сигнальных проводов; это отдельная программная задача |

Предлагаемый следующий шаг — UART. На ESP32 доступны аппаратные UART с
маршрутизацией сигналов через GPIO; на ESP8266 можно использовать
SoftwareSerial. Его надёжность зависит от скорости и нагрузки, поэтому для
первой проверки разумно начать с **9600 бод, 8N1**, затем измерить ошибки
и потери. Это исходная настройка для будущего теста, а не подтверждённая
скорость данной сборки. [ESP32 GPIO и периферийная матрица](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/api-reference/peripherals/gpio.html),
[ESP8266 Arduino Core: SoftwareSerial](https://arduino-esp8266.readthedocs.io/en/latest/libraries.html#softwareserial),
[EspSoftwareSerial: ограничения времени и буферов](https://github.com/plerup/espsoftwareserial).

## Предлагаемая распиновка

Ниже названия **контактов платы**, а не номера ножек микросхемы. На D1 mini
`D6` означает `GPIO12`, а `D7` — `GPIO13`. Это подтверждено официальной
таблицей обычного D1 mini v3.1.0; все его цифровые входы и выходы работают
с уровнем 3,3 В. Точная ревизия имеющейся платы и её USB-разъём здесь
не установлены: перед подключением сверьте надписи на своей плате с её
схемой. Никакие перемычки на ней не предполагаются.
[Официальная распиновка D1 mini v3.1.0](https://www.wemos.cc/en/latest/d1/d1_mini_3.1.0.html#pin),
[страница D1 mini и схемы ревизий](https://www.wemos.cc/en/latest/d1/d1_mini.html).

| ESP32 | Направление | D1 mini / ESP8266 |
|---|---|---|
| `GPIO25`, будущий UART TX | → | `D6 / GPIO12`, SoftwareSerial RX |
| `GPIO34`, будущий UART RX | ← | `D7 / GPIO13`, SoftwareSerial TX |
| `GND` | общий провод | `G / GND` |

Передача перекрёстная: **TX одной платы подключается к RX другой**.
Обе стороны должны использовать обычный UART с логическими уровнями 3,3 В,
без инверсии; это не интерфейс RS-232 с положительным и отрицательным
напряжением. Подавать 5 В на сигнальные контакты нельзя.

`GPIO34` ESP32 подходит только для приёма: это вход без встроенной подтяжки.
`GPIO25` допускает выход. Эти свойства относятся к классическому ESP32,
используемому данной сборкой, и не являются распиновкой всех плат семейства
ESP32. [Официальные ограничения GPIO ESP32](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/api-reference/peripherals/gpio.html#gpio-summary).

На D1 mini контакты `TX/RX` оставлены его USB-прошивке и диагностике.
Предлагаемые `D6/D7` используют SoftwareSerial и не могут одновременно
обслуживать другое подключённое к этим контактам SPI-устройство.

## Что уже занято в ESP-HACK

По текущему `src/CONFIG.h` GPIO25 называется **GPIO_F** и доступен функциям
пользовательского GPIO. Поэтому будущий UART потребует явного резервирования
GPIO25: пользоваться GPIO_F и этим UART одновременно нельзя. Сейчас код
его не резервирует и не запускает UART на GPIO25/34.

Предложение не пересекается с установленными OLED, SD, CC1101 и кнопками:

| Узел | GPIO текущей сборки |
|---|---|
| OLED | SDA 21, SCL 22 |
| SD, отдельный HSPI | MOSI 13, CLK 14, MISO 17, CS 15 |
| CC1101, VSPI | MOSI 23, SCK 18, MISO 19, CS 5, GDO0 4 |
| Кнопки | UP 27, DOWN 26, OK 33, BACK 32 |

Эти номера относятся к **ESP32**. Одноимённые GPIO12/13 на отдельной D1 mini
не соединены с ESP32 SD-шиной и сами по себе с ней не конфликтуют. Провода
установленных устройств переставлять не нужно.

## Питание и порядок будущей проверки

1. Отключить питание обеих плат и сверить подписи контактов.
2. Подключить только три провода по таблице: TX→RX, RX←TX и GND↔GND.
3. Питать каждую плату через её собственный USB. Контакты `5V` и `3V3`
   между платами в этом варианте **не соединять**. При отключении одной
   платы выключать обе либо разъединять сигнальные провода.
4. После разработки обеих прошивок проверить в обоих направлениях
   короткое сообщение с номером и контрольной суммой на 9600 бод, 8N1.
   Затем проверить потери при работе OLED, SD, радио и Wi-Fi; отдельно
   проверить перезагрузку каждой платы и восстановление связи.

Пункты с обменом сообщениями остаются планом испытаний. Ни работоспособность
моста, ни отсутствие потерь, ни совместимость конкретного клона D1 mini
физически не подтверждены. Основная рабочая прошивка ESP32 продолжает
использовать существующую распиновку и не требует новой платы.
