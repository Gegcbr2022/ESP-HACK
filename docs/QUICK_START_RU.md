# Быстрый запуск ESP-HACK Radio Lab

Версия `v1.3-rf-lab.2`: ESP32 / SH1106 / CC1101 / microSD, исходная распиновка.
В комплекте 11 Lua-приложений. Новые приложения устанавливаются на SD без
повторной сборки и прошивки устройства.

## Главное меню Pocket

Pocket показывает три пункта с иконками, выделение, номер позиции, полосу
прокрутки и состояние SD. **UP/DOWN** выбирают пункт, **OK** открывает,
**BACK** возвращает назад. Значок SD означает доступность карты, а не заряд
аккумулятора или передачу по радио.

Другой вид меню выбирается через **Settings → Interface → Menu**: Pages, List,
Wii, DSi или Pocket. Обновление переводит главное меню на Pocket; последующий
выбор стиля сохраняется. Подробности — [Pocket UI](POCKET_UI.md).

## Приложения на SD

Откройте **SD Apps**, затем группу **All apps**, **Tools**, **Games**, **Radio**,
**Favorites** или **Recent**. UP/DOWN выбирают, короткое OK запускает приложение.
Долгое OK на приложении открывает описание и информацию о файле. На этом
экране OK добавляет/удаляет избранное, UP/DOWN переключают страницы информации.
Сохраняются до восьми избранных и четырёх последних приложений.

**Удержание BACK закрывает любое приложение.** Короткое BACK в некоторых играх
и инструментах выполняет действие, поэтому для выхода используйте удержание.

### Игры

| Файл | Управление |
|---|---|
| `snake.lua` | UP поворачивает налево относительно движения, DOWN направо; OK начинает, ставит на паузу и перезапускает после проигрыша; короткое BACK выходит. |
| `game2048.lua` | UP вверх, DOWN вниз, OK вправо, короткое BACK влево. OK начинает и перезапускает после проигрыша. |
| `blockfall.lua` | UP вращает фигуру, DOWN опускает на ряд, удержание DOWN сбрасывает вниз; OK вправо, короткое BACK влево. OK начинает и перезапускает. |
| `mines.lua` | UP/DOWN выбирают предыдущую/следующую клетку, OK открывает, короткое BACK ставит/снимает флаг. OK начинает и перезапускает после победы или проигрыша. |

Правила, размеры полей и ограничения — [SD Games](SD_GAMES.md). Прогресс и
счёт существуют только до выхода из игры.

### Инструменты

| Файл | Управление |
|---|---|
| `countdown.lua` | UP/DOWN меняют минуты или секунды, OK выбирает следующее поле и запускает; во время отсчёта OK — пауза/продолжение, BACK — редактирование. После окончания OK повторяет отсчёт. Сигнал только на экране. |
| `calculator.lua` | UP/DOWN меняют выбранное число или операцию; OK переключает A, операцию и B; короткое BACK меняет шаг ввода от 0,01 до 100000. |
| `unit_converter.lua` | UP/DOWN меняют число, OK выбирает следующее направление перевода единиц, BACK меняет шаг. Вход и результат показываются с двумя знаками после запятой. |
| `resistor_codes.lua` | UP/DOWN меняют цвет выбранной полосы, OK выбирает следующую полосу, BACK переключает четыре/пять полос. |
| `hello.lua` | OK/DOWN — следующее приветствие, UP — предыдущее, BACK — выход. |
| `stopwatch.lua` | OK — старт/пауза, UP — промежуточное время, DOWN — сброс, BACK — выход. |
| `rf_dashboard.lua` | В группе Radio: OK включает/выключает приём на 433,920 МГц / AM270; BACK останавливает и выходит. Приложение не передаёт. |

Диапазоны, формулы и ограничения — [SD Utilities](SD_UTILITIES.md).

### Установка своего приложения

Файлы лежат непосредственно в `/apps` на карте. Группы определяются комментариями
в начале файла; описание и пример — в [SDK](APPS_SDK.md). Формат приложения —
текстовый `.lua`, а не Flipper `.fap`. Имя содержит латинские буквы, цифры,
`_` или `-` и заканчивается на `.lua`; полный размер имени — до 40 символов.
Исходник — до 32 КиБ, память Lua — 48 КиБ. Каталог показывает до 32 приложений.

Для установки по USB вернитесь в главное меню и закройте другие мониторы порта:

```powershell
python -m pip install pyserial
python scripts/install_app.py --port COM4 examples/lua_apps/countdown.lua
```

Замените COM4 текущим портом устройства, а путь — своим файлом. Подтверждение
`APP_INSTALLED` означает совпадение размера и SHA256, включая повторное чтение
записанного файла с SD. Это проверка установки, а не успешного выполнения кода.
Вместо USB файл можно скопировать на карту вручную.

## Простой чат с Flipper

Для вашего согласованного испытания в клетке Фарадея:

1. На Flipper откройте Enhanced Sub-GHz Chat, выберите **433.920 MHz** и
   **No encryption**.
2. На ESP32 откройте **SubGHz → Radio Lab → Sub-GHz Chat**. Экран чата сам
   применяет 433,920 МГц, Flipper plaintext и номинальные 0 dBm. Передача готова
   к ручной отправке; автоматических сообщений нет.
3. Нажмите OK: откроется меню отправки, где уже выбран **TEST123**. Нажмите OK
   ещё раз для отправки. Также доступны Hello, OK и **Write message**.
4. На экране чтения UP выбирает более старое сообщение. DOWN показывает
   следующую часть длинного текста или более новое сообщение. BACK закрывает
   чат и восстанавливает прежние радионастройки.

Для своего текста выберите Write message: UP/DOWN выбирают символ, OK добавляет,
короткое BACK удаляет; удержание OK завершает ввод, удержание BACK отменяет.
Предел — 160 печатных ASCII-символов, без кириллицы.

**Sent означает только завершение локальной передачи.** В Flipper plaintext нет
подтверждения от второго устройства и нет шифрования. Пользователь сообщил,
что на предыдущей прошивке сообщения не приходили в обе стороны. Успешный
обмен по радио пока не установлен; новая настройка и диагностика не являются
подтверждением исправления.

В пункте **Advanced** меню отправки остаётся отдельный ESP ACK-протокол с
подтверждениями и поставляемым `esphack_subghz_chat.fap`. Этот FAP собран для
официального SDK 1.5.1 / API 88.2; он не требуется для обычного plaintext-режима
Enhanced Chat. [Форматы и совместимость](FLIPPER_CHAT_COMPATIBILITY.md).

## Остальная радиолаборатория

В **SubGHz → Radio Lab** доступны Read/RAW, настройки и пресеты, анализ частоты
и спектра, анализ записей, менеджер файлов, конечный тестовый генератор,
Music Lab и диагностика. Исходные разделы ESP-HACK сохранены.

Для этих передающих функций профиль **Shielded laboratory** выбирается явно
в Radio Settings. Простой чат отдельно включает временный профиль для
согласованного стенда; после выхода прежние настройки возвращаются. Ограничения
длительности, интервала между пакетами и локального бюджета передачи действуют
и в чате. Номинальные значения мощности не являются измерением реального RF.

## Диагностика и восстановление

Через последовательный порт 115200 доступны `rfdiag`, `chatstat` и `appsdiag`.
Последняя команда проверяет VM, ограничитель выполнения и до 120 кадров каждого
из 11 установленных примеров; запуск приёмника из Lua на время проверки запрещён.
Итог конкретного устройства смотрите в [отчёте](TEST_REPORT.md). Проверка SPI,
установка файла и показ экрана не доказывают приём сообщения по радио.

Оригинальный полный дамп, JSON-квитанцию и SHA256 храните вместе. Это отдельный
приватный бекап; публичная сборка исходников его не заменяет.
[Сборка, прошивка и восстановление](BUILD_AND_FLASH.md).
