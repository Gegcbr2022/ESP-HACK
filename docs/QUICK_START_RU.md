# Быстрый запуск ESP-HACK Radio Lab

Сборка: `v1.3-rf-lab.1`, ESP32 / SH1106 / CC1101 / SD, исходная распиновка.

## Приложения без перепрошивки

Откройте **SD Apps** в главном меню. Примеры:

- `hello.lua` — приветствия и счётчик;
- `stopwatch.lua` — секундомер с промежуточным временем;
- `rf_dashboard.lua` — приём на 433,920 МГц, RSSI и индикатор несущей.

UP/DOWN выбирают приложение, OK запускает. Удержание BACK закрывает приложение.
В примерах короткое BACK тоже завершает работу. В радиопанели OK включает и
выключает приёмник. Новые приложения — текстовые `.lua`, а не Flipper `.fap`.

Установка по USB, когда устройство находится в главном меню:

```powershell
python -m pip install pyserial
python scripts/install_app.py --port COM4 examples/lua_apps/hello.lua
```

Для своего приложения укажите его файл вместо примера. При необходимости
замените COM4 текущим портом устройства. Подтверждение `APP_INSTALLED` означает,
что размер и SHA256 совпали, включая повторное чтение записанного файла с SD.
Файл также можно скопировать на SD вручную в `/apps`.

[SDK и шаблон приложения](APPS_SDK.md): рисование на экране, кнопки, время и
приёмные измерения. На приложение выделяется 48 КиБ памяти Lua, исходник — до
32 КиБ. Ошибка или превышение бюджета останавливают приложение.

## Радиолаборатория

Откройте **SubGHz → Radio Lab**. Доступны приём/RAW, настройки и пресеты,
частотный и спектральный анализ, анализ записей, менеджер файлов, тестовый
генератор, Music Lab, чат и диагностика. Исходные разделы ESP-HACK сохранены.

Для физического Flipper установите `esphack_subghz_chat.fap` в
`/ext/apps/Sub-GHz/`. Сборка FAP проверена с официальным SDK 1.5.1 / API 88.2.
Оба участника чата должны использовать одинаковый канал и профиль. Чат
передаёт до 160 ASCII-символов; шифрование не реализовано.

Новые передающие функции после входа в лабораторию выключены. Профиль
**Shielded laboratory** выбирается явно в Radio Settings для испытательного
стенда. Результаты реальных радиопроверок указаны отдельно в
[отчёте](TEST_REPORT.md); проверка SPI не заменяет проверку эфира.

## Диагностика и откат

На главном меню через последовательный порт 115200 можно отправить `rfdiag`
или `appsdiag`. Последняя команда проверяет VM, ограничитель выполнения и три
установленных примера; во время этой проверки запуск приёмника заблокирован.

Оригинальный полный дамп устройства, JSON-квитанцию и SHA256 храните вместе.
Это отдельный приватный бекап; публичная исходная сборка его не заменяет.
[Сборка, прошивка и восстановление](BUILD_AND_FLASH.md).
