# Быстрый запуск ESP-HACK Radio Lab

Версия `v1.3-rf-lab.2`: ESP32 / SH1106 / CC1101 / microSD, исходная распиновка.
В комплекте 11 Lua-приложений. Новые приложения устанавливаются на SD без
повторной сборки и прошивки устройства.

## Главное меню Pocket

Pocket показывает три пункта с иконками, выделение, номер позиции, полосу
прокрутки и состояние SD. **UP/DOWN** выбирают пункт, **OK** открывает,
**BACK** возвращает назад. Значок SD означает доступность карты, а не заряд
аккумулятора или передачу по радио.

Пункты главного меню: **Wi-Fi**, **Bluetooth**, **Радио SubGHz**,
**Инфракрасный**, **Пины GPIO**, **Игры**, **Настройки**, **Приложения SD**.
Новые экраны и приложения показывают русский текст. Часть прежних разделов
ESP-HACK и технических сообщений пока сохраняет английские названия.

Другой вид меню выбирается через **Настройки → Интерфейс → Главное меню**: Pages, List,
Wii, DSi или Pocket. Обновление переводит главное меню на Pocket; последующий
выбор стиля сохраняется. Подробности — [Pocket UI](POCKET_UI.md).

## Приложения на SD

Откройте **Приложения SD**, затем группу **Все приложения**, **Инструменты**,
**Игры**, **Радио**, **Избранное** или **Недавние**. UP/DOWN выбирают, короткое
OK запускает приложение.
Долгое OK на приложении открывает описание и информацию о файле. На этом
экране OK добавляет/удаляет избранное, UP/DOWN переключают страницы информации.
Сохраняются до восьми избранных и четырёх последних приложений.

**Удержание BACK закрывает любое приложение.** Короткое BACK в некоторых играх
и инструментах выполняет действие, поэтому для выхода используйте удержание.
В подсказках на маленьком экране **DN** означает DOWN, **BK** означает BACK.

### Игры

| На экране / файл | Управление |
|---|---|
| Змейка / `snake.lua` | UP поворачивает налево относительно движения, DOWN направо; OK начинает, ставит на паузу и перезапускает после проигрыша; короткое BACK выходит. |
| 2048 / `game2048.lua` | UP вверх, DOWN вниз, OK вправо, короткое BACK влево. OK начинает и перезапускает после проигрыша. |
| Падающие блоки / `blockfall.lua` | UP вращает фигуру, DOWN опускает на ряд, удержание DOWN сбрасывает вниз; OK вправо, короткое BACK влево. OK начинает и перезапускает. |
| Сапёр / `mines.lua` | UP/DOWN выбирают предыдущую/следующую клетку, OK открывает, короткое BACK ставит/снимает флаг. OK начинает и перезапускает после победы или проигрыша. |

Правила, размеры полей и ограничения — [SD Games](SD_GAMES.md). Прогресс и
счёт существуют только до выхода из игры.

### Инструменты

| На экране / файл | Управление |
|---|---|
| Таймер / `countdown.lua` | UP/DOWN меняют минуты или секунды, OK выбирает следующее поле и запускает; во время отсчёта OK — пауза/продолжение, BACK — редактирование. После окончания OK повторяет отсчёт. Сигнал только на экране. |
| Калькулятор / `calculator.lua` | UP/DOWN меняют выбранное число или операцию; OK переключает A, операцию и B; короткое BACK меняет шаг ввода от 0,01 до 100000. |
| Перевод единиц / `unit_converter.lua` | UP/DOWN меняют число, OK выбирает следующее направление перевода единиц, BACK меняет шаг. Вход и результат показываются с двумя знаками после запятой. |
| Коды резисторов / `resistor_codes.lua` | UP/DOWN меняют цвет выбранной полосы, OK выбирает следующую полосу, BACK переключает четыре/пять полос. |
| Приветствие / `hello.lua` | OK/DOWN — следующее приветствие, UP — предыдущее, BACK — выход. |
| Секундомер / `stopwatch.lua` | OK — старт/пауза, UP — промежуточное время, DOWN — сброс, BACK — выход. |
| Радиопанель / `rf_dashboard.lua` | В группе Радио: OK включает/выключает приём на 433,920 МГц / AM270; BACK останавливает и выходит. Приложение не передаёт. |

Диапазоны, формулы и ограничения — [SD Utilities](SD_UTILITIES.md).

### Установка своего приложения

Файлы лежат непосредственно в `/apps` на карте. Группы определяются комментариями
в начале файла; описание и пример — в [SDK](APPS_SDK.md). Формат приложения —
текстовый `.lua`, а не Flipper `.fap`. Имя содержит латинские буквы, цифры,
`_` или `-` и заканчивается на `.lua`; полный размер имени — до 40 символов.
Исходник — до 32 КиБ, память Lua — 48 КиБ. Каталог показывает до 32 приложений.
Название и описание внутри комментариев могут быть на русском: до 21 и 64
знаков соответственно. Имена файлов остаются латинскими. `ui.text` принимает
печатный ASCII и русские буквы, включая Ё/ё; другие алфавиты и эмодзи не
поддерживаются. Строка API ограничена 160 байтами, а видимая строка при обычном
шрифте — 21 знаком. Это разные ограничения.

Для установки по USB вернитесь в главное меню и закройте другие мониторы порта:

```powershell
python -m pip install pyserial
python scripts/install_app.py --port COM4 examples/lua_apps/countdown.lua
```

Замените COM4 текущим портом устройства, а путь — своим файлом. Подтверждение
`APP_INSTALLED` означает совпадение размера и SHA256, включая повторное чтение
записанного файла с SD. Это проверка установки, а не успешного выполнения кода.
Вместо USB файл можно скопировать на карту вручную.

## Простой чат с Flipper

Для вашего согласованного испытания в клетке Фарадея:

1. На Flipper откройте Enhanced Sub-GHz Chat, выберите **433.920 MHz** и
   **No encryption**.
2. На ESP32 откройте **Радио SubGHz → Чат Flipper**. Экран чата сам
   применяет 433,920 МГц, Flipper plaintext и номинальные 0 dBm. Передача готова
   к ручной отправке; автоматических сообщений нет.
3. Нажмите OK: откроется меню **Отправить**, где уже выбран **Тест TEST123**.
   Нажмите OK ещё раз для отправки. Также доступны **Привет (Hello)**,
   **Ответ OK** и **Написать текст**. Русские подписи не меняют текст в эфире:
   отправляются `Hello`, `TEST123` или `OK`.
4. На экране чтения UP выбирает более старое сообщение. DOWN показывает
   следующую часть длинного текста или более новое сообщение. BACK закрывает
   чат и восстанавливает прежние радионастройки.

Для своего текста выберите **Написать текст**: появится клавиатура **8 × 4**,
сверху — хвост текста и счётчик длины. UP/DOWN выбирают клавишу, удержание
UP/DOWN меняет страницу, OK вводит символ или действие. **SP** — пробел,
**<-** — стереть, **>>** — следующая страница, **OK** — закончить ввод.
Короткое BACK стирает, удержание BACK отменяет и сохраняет исходное значение.
Удержание OK тоже завершает ввод. В обычном меню чата завершение непустого
текста ставит его в очередь на отправку; отмена ничего не отправляет.
Предел — 160 печатных ASCII-символов, без кириллицы. Поля частоты, HEX и имени
файла показывают свой допустимый набор. [Подробное управление](KEYBOARD_RU.md).

**Надпись об отправке означает только завершение локальной передачи.** В Flipper plaintext нет
подтверждения от второго устройства и нет шифрования. Пользователь сообщил,
что на прошивке `c5779ee` сообщения не приходили в обе стороны. Позже получены
контрольные пакеты Flipper → ESP32 с верным CRC после индивидуальной частотной
коррекции. Финальная прошивка `d63f1ca` прошла обмен в обе стороны между обычным
экраном чата ESP32 и CLI установленного Flipper с внутренним радио на номинальных
433,920 МГц. Для этого ESP32 сохранена индивидуальная поправка +115 ppm;
не переносите её на другой модуль без проверки. Графическое приложение
Enhanced Chat в этой финальной проверке не запускалось. Дальность и реальная
мощность не измерены; завершение локальной передачи само по себе не подтверждает доставку.
Эта проверка относится к прежней `d63f1ca`; новый вариант `087f9b6` с видимой
клавиатурой проходит отдельную проверку на устройстве.

В пункте **Дополнительно** меню отправки остаётся отдельный ESP ACK-протокол с
подтверждениями и поставляемым `esphack_subghz_chat.fap`. Этот FAP собран для
официального SDK 1.5.1 / API 88.2; он не требуется для обычного plaintext-режима
Enhanced Chat. [Форматы и совместимость](FLIPPER_CHAT_COMPATIBILITY.md).

## Приём сигнала и файлы .sub

Откройте **Радио SubGHz**. Здесь пять пунктов:

- **Принять сигнал** — подождите нажатия кнопки своего пульта. Когда появится
  «Принято: OK записать», нажмите OK для сохранения на SD в `/subghz`.
  Записывается один завершённый сигнал RAW, до 2048 импульсов. При переполнении,
  потерях или отсутствии целого сигнала запись не сохраняется. BACK выходит.
- **Файлы .sub** — просмотр файлов и папок `/subghz`; OK открывает папку или
  меню файла: **Отправить**, **О файле**, **Ещё**. Для передачи выберите
  **Отправить**, проверьте частоту и удерживайте OK. BACK отменяет. Обычное
  нажатие OK само сигнал не передаёт. На странице до 39 файлов и папок; если
  есть продолжение, внизу появляется **След. страница**. Заголовок показывает
  страницу и общее число записей. Удержание DOWN/UP быстро меняет страницу.
  BACK сначала возвращает на предыдущую страницу, затем в родительскую папку;
  удержание BACK выходит. При смене папки или поиска открывается первая страница.
  Полный путь может занимать до 1023 байт UTF-8; короткая подпись в списке не
  меняет настоящее имя файла. Более длинный путь отклоняется с сообщением.
- **Чат Flipper** — чат по инструкции выше.
- **Настройки** — UP/DOWN выбирают поле «Частота» или «Сигнал», OK меняет
  значение, BACK возвращает. Частоты здесь — 433,920 и 868,350 МГц; сигналы —
  два AM/OOK и три FM-пресета. По умолчанию выбран 433,920 МГц / AM270.
- **Дополнительно** — технические инструменты и полные настройки.

Файл `.sub` из интернета не обязательно можно передать этим устройством.
Просмотр метаданных и передача — разные операции. Поддерживаются двоичный OOK
RAW до 2048 интервалов / 5 секунд, а также точные протоколы `RcSwitch`
(protocol 1, от 1 до 32 бит), `Princeton` (от 1 до 32 бит) и `CAME` (12/24 бита).
Официальный формат Flipper Princeton — 24 бита; остальные ширины Princeton
поддерживаются как расширение прежних входных файлов ESP-HACK. Названия
протоколов не угадываются. RAW передаётся один раз, статический код — шесть периодов.
Передача разрешена только на точных частотах файла **433,920 или 868,350 МГц**;
другие частоты доступны для просмотра и не подменяются разрешённой частотой.
FSK RAW, неизвестные пресеты, остальные декодированные протоколы и плавающие
коды не превращаются автоматически в поддерживаемую запись. В частности,
прочитанный `Alutech AT-4N` остаётся файлом динамического протокола без кодировщика.
Переименование или смена расширения не меняет формат сигнала. Не подменяйте
частоту или тип модуляции только для обхода ошибки.
Если файл отклонён, сохраните показанный текст ошибки и проверьте его формат.
Экран показывает фактический Protocol; неподдерживаемая частота означает
отдельное ограничение канала, а не динамический код. Длинные русские имена
в новом браузере не требуют переименования.
[Поддерживаемые файлы и ограничения](STATIC_SUB_PLAYBACK.md).

Для согласованного стенда **Отправить** временно включает лабораторный профиль
с номинальными 0 dBm и пределом 5 секунд; после передачи или отмены возвращает
прежние настройки. Этот экран, как и чат, не требует предварительно включать
передачу в технических настройках. Повторов по таймеру и автоматической
отправки при открытии файла нет.

## Дополнительные радиоинструменты

В **Радио SubGHz → Дополнительно** доступны настройки и пресеты, анализ частоты
и спектра, анализ записей, менеджер файлов, конечный тестовый генератор,
Music Lab и диагностика. Исходные разделы ESP-HACK сохранены.

Для этих передающих функций профиль **Shielded laboratory** выбирается явно
в **Все настройки радио**. Простой чат и пункт **Отправить** для файлов отдельно
включают временный профиль для согласованного стенда; после выхода прежние
настройки возвращаются. Для файла действует предел одной передачи 5 секунд.
В чате отдельно действуют интервал между пакетами и минутный бюджет попыток
передачи. Номинальные значения мощности не являются измерением реального RF.

## Диагностика и восстановление

Через последовательный порт 115200 доступны `rfdiag`, `chatstat` и `appsdiag`.
Последняя команда проверяет VM, ограничитель выполнения и до 120 кадров каждого
из 11 установленных примеров; запуск приёмника из Lua на время проверки запрещён.
Итог конкретного устройства смотрите в [отчёте](TEST_REPORT.md). Проверка SPI,
установка файла и показ экрана не доказывают приём сообщения по радио.
На финальном `d63f1ca` все 11 приложений прошли по 120 диагностических кадров;
приём радио во время этой проверки был отключён.
Команда `chatedit` в уже открытом чате показывает проверочный редактор: его
черновик всегда отбрасывается, даже после завершения ввода; передачи нет.
Это отличается от обычного пункта **Написать текст**. Для клавиатурной сборки
`087f9b6` новые физические результаты будут записаны отдельно.

Оригинальный полный дамп, JSON-квитанцию и SHA256 храните вместе. Это отдельный
приватный бекап; публичная сборка исходников его не заменяет.
[Сборка, прошивка и восстановление](BUILD_AND_FLASH.md).
